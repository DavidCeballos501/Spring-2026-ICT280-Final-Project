# Spring-2026-ICT280-Final-Project
Final Project for ICT280 Spring 2026 Semester

# Project Description
This website was designed for the Module 15 final project client profile assignment. The client provided was GreenTech Solutions which is a startup company that incorporates environmental issues and technology. The website is designed to inform users about the company, display products/services offered, offer short sustainability articles/videos, and allow visitors a way to contact the company.

# Live Site
https://DavidCeballos501.github.io/Spring-2026-ICT280-Final-Project/

# Pages Included
- `index.html` - homepage with mission and featured products
- `about.html` - company story, values, and timeline table
- `products.html` - product catalog with search and filter
- `blog.html` - resource articles and newsletter signup
- `contact.html` - contact information and contact form

# Features Used
- Semantic HTML5 structure with `header`, `nav`, `main`, `section`, `article`, `footer`, and `address`
- External CSS stylesheet
- Flexbox layout
- Responsive design with a media query
- Images with alt text
- Table on the About page
- Forms on the Blog and Contact pages
- JavaScript interactivity:
  - Mobile menu button
  - Product search
  - Product category filter
  - Read more buttons
  - Form messages
  - High contrast accessibility option
